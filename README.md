# 云上慢旅 · 丽江 × 香格里拉 6天5晚

一个以丽江和香格里拉为主题的旅行视觉与行程展示项目，使用沉浸式首屏、时间线、卡片、动画和本地素材，把一份旅行规划做成可浏览的数字手册。

> 在线主页：[打开云上慢旅](https://yusheng266186-beep.github.io/lijiang-travel/)  
> 详细整合版：[打开 cinematic-guide](https://yusheng266186-beep.github.io/lijiang-travel/cinematic-guide/)  
> GitHub：[查看源代码](https://github.com/yusheng266186-beep/lijiang-travel)

## 项目定位

本仓库同时保留两个层次的页面：

1. 根目录 index.html：Pages 首页使用的“云上慢旅”主视觉版；
2. cinematic-guide/：更完整的丽江×香格里拉六日慢度假详细版。

两者围绕同一条旅行主题线，但承担不同任务：

- 根页面强调氛围、视觉和快速浏览；
- cinematic-guide 强调详细行程、文化预习、摄影、美食、备选方案、预算和清单。

如果需要快速展示，使用根页面；如果需要真正拿来规划旅行，建议打开 cinematic-guide。

## 内容主题

- 丽江古城与纳西文化；
- 香格里拉高原体验；
- 六天五晚双人慢旅行；
- 酒店作为旅行主场；
- 每天一个主要场景；
- 雨季、高原、交通和身体状态预案；
- 摄影氛围、美食选择和出发清单。

项目的核心取舍是“保留余量”。它不把景点数量作为唯一目标，而是通过住宿、交通、休息和备选方案让行程更舒服。

## cinematic-guide 详细功能

### 行程与决策

- 六日详细时间轴；
- 每日主题、交通和住宿信息；
- 香格里拉出行日期判断；
- 天气、身体状态、交通预警和车票确认规则；
- 停损线：出现明显不适或交通风险时及时缩短行程；
- 备选景点和替换策略。

### 文化预习

- 丽江、香格里拉及沿线文化线索；
- 点击或翻转卡片查看观察关键词；
- 帮助旅行者在到达景点前理解当地空间和生活方式。

### 摄影与美食

- 摄影氛围指南；
- 不同地点的光线、构图和拍摄节奏建议；
- 云南地方美食清单；
- 推荐店、地址线索、口味和点餐注意事项；
- 不把推荐店铺当作实时营业承诺。

### 预算与清单

- 预算参考；
- 预约和出发清单；
- 清单勾选状态保存在当前浏览器；
- 支持重置本机勾选；
- 适合旅行前准备和旅途中快速查阅。

## 使用方式

### 在线使用

- 视觉主页：[lijiang-travel](https://yusheng266186-beep.github.io/lijiang-travel/)
- 详细手册：[cinematic-guide](https://yusheng266186-beep.github.io/lijiang-travel/cinematic-guide/)

### 本地预览

根页面可以直接打开 index.html。详细版建议在仓库根目录启动静态服务器：

    python -m http.server 8080

然后访问：

    http://localhost:8080/cinematic-guide/

这样相对路径、脚本、样式和 media 目录的加载会更稳定。

## 目录结构

    lijiang-travel/
    ├── index.html                  # Pages 根页面，视觉展示版
    └── cinematic-guide/
        ├── index.html              # 详细整合版入口
        ├── script.js               # 行程、卡片、清单和交互逻辑
        ├── styles.css              # 详细版样式
        └── media/                  # 详细版媒体资源

根目录 index.html 内含较多视觉资源，仓库体积较大。修改前建议先下载或保留当前版本备份。

## 技术实现

- 原生 HTML、CSS 和 JavaScript；
- CSS Variables 统一颜色、字体、间距和动效；
- 响应式布局；
- CSS transition、transform 和自定义缓动；
- cinematic-guide 使用独立 script.js 和 styles.css；
- 部分字体和图片通过相对路径或外部资源加载；
- GitHub Pages 静态托管。

项目没有 npm 构建流程，修改后提交到 main 分支即可触发 Pages 更新。

## 修改建议

### 修改根页面

- 先确认根 index.html 是否仍然作为 Pages 首页；
- 修改标题、首屏文字和导航时同步检查移动端；
- 不要随意替换内嵌图片数据，以免造成页面体积明显变化；
- 发布前在手机和桌面浏览器各检查一次。

### 修改 cinematic-guide

- 内容和交互主要在 script.js；
- 视觉样式主要在 styles.css；
- 页面结构和章节锚点在 cinematic-guide/index.html；
- 修改导航或章节 id 时要同步更新跳转链接；
- 清单功能使用浏览器本地存储，测试时注意清除旧状态。

## 旅行信息提示

交通班次、天气、酒店服务、景区开放、门票和餐厅营业情况都会变化。页面中的日期、车次、价格和店铺仅作规划参考，出发前请通过 12306、景区官方渠道、酒店和地图平台重新确认。
